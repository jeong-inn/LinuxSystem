# SSU-Score (2023 설계과제 2)

`ssu_score`는 정답 디렉토리를 기준으로 학생별 빈칸 답안(`.txt`)과 프로그램 답안(`.c`)을 자동 채점하고, 문제별 점수와 총점을 CSV로 저장하는 Linux용 채점 프로그램이다. 이 구현은 제공된 2023 설계과제 2 명세의 기본 기능과 8개 옵션을 반영한다.

## 1. 구현 범위

- 최대 100개 학생 디렉토리와 최대 100개 문제를 탐색한다.
- 문제 목록, 학생 목록, 오답 목록을 연결 리스트로 관리한다.
- 빈칸 문제는 복수 정답, 공백 차이, 연산자 우선순위, 일부 교환·관계 연산의 동치 표현을 비교한다.
- 프로그램 문제는 정답과 학생 소스를 컴파일·실행하고 출력 결과를 비교한다.
- 프로그램 출력은 파일 크기를 미리 제한하지 않고 스트림 방식으로 비교한다.
- 컴파일 경고 한 건당 `0.1`점을 감점하고, 컴파일 오류 또는 5초 이상 실행되는 답안은 해당 문제를 0점 처리한다.
- 기본 결과 파일 `ANS_DIR/score.csv`와 배점 파일 `ANS_DIR/score_table.csv`를 관리한다.
- `-n`, `-m`, `-c`, `-p`, `-t`, `-s`, `-e`, `-h` 옵션을 지원한다.
- 외부 컴파일러와 실행 파일은 `posix_spawn()`으로 실행한다. 명세에서 금지한 `system()`, `popen()`, `fork()`, `exec()` 계열 함수는 사용하지 않는다.

## 2. 파일 구성

```text
completed/
├── Makefile
├── README.md
├── main.c          # 수행 시간 측정 및 프로그램 진입점
├── ssu_score.c     # 옵션, 탐색, 채점, CSV, 실행 제어
├── ssu_score.h     # 공통 상수와 공개 함수
├── blank.c         # 빈칸 답안 토큰화·구문 트리 비교
└── blank.h
```

`make` 실행 뒤에는 `ssu_score` 실행 파일과 오브젝트 파일이 생성된다.

## 3. 빌드 환경과 방법

필요 조건은 POSIX 호환 환경, C11 컴파일러, `make`이다. 채점 대상 C 프로그램을 다시 컴파일하므로 실행 환경의 `PATH`에서 `gcc`도 찾을 수 있어야 한다.

```sh
make
```

빌드 결과를 제거하려면 다음을 실행한다.

```sh
make clean
```

Makefile은 `-std=c11 -Wall -Wextra -Wpedantic -O2`로 본 프로젝트를 컴파일한다.

## 4. 입력 디렉토리 구조

### 정답 디렉토리

```text
ANS_DIR/
├── 1-1.txt
├── 1-2.txt
├── 2.c
└── score_table.csv   # 없으면 최초 실행 시 생성
```

- 빈칸 문제 이름은 `문제번호.txt` 또는 `주문제-하위문제.txt` 형식이다.
- 프로그램 문제 이름은 `문제번호.c` 형식이다.
- 한 빈칸 문제에 정답이 여러 개 있으면 정답 파일에서 `:`으로 구분한다.
- 실행 중 프로그램 정답의 `문제번호.exe`와 `문제번호.stdout`이 정답 디렉토리에 생성 또는 갱신된다.
- 파일 이름에 쉼표나 줄바꿈이 있으면 CSV 구조를 안전하게 유지할 수 없으므로 오류 처리한다.

### 학생 디렉토리

```text
STD_DIR/
├── 20230001/
│   ├── 1-1.txt
│   ├── 1-2.txt
│   └── 2.c
└── 20230002/
    ├── 1-1.txt
    └── 2.c
```

- `STD_DIR` 바로 아래의 각 디렉토리 이름을 학번으로 사용한다.
- 제출 파일이 없으면 해당 문제는 0점이다.
- 프로그램 채점 시 학생 디렉토리에 `문제번호.stdexe`와 `문제번호.stdout`이 생성 또는 갱신된다.
- 채점 프로그램은 제출 프로그램에 표준 입력을 제공하지 않는다. 입력을 기다리는 프로그램은 5초 제한에 걸리거나 입력 종료를 받는다.

## 5. 기본 실행

```sh
./ssu_score <STD_DIR> <ANS_DIR> [OPTION]
```

예:

```sh
./ssu_score ./STUDENT ./ANS
```

두 디렉토리 인자는 상대 경로와 절대 경로를 모두 허용한다. 존재하지 않거나 디렉토리가 아니면 채점을 시작하지 않는다.

채점 순서는 다음과 같다.

1. 정답 문제와 학생 디렉토리를 찾고 문제 번호 순, 학번 순으로 정리한다.
2. `score_table.csv`를 읽거나 새로 만든다.
3. 프로그램 정답을 컴파일하고 한 번 실행해 기준 출력을 만든다.
4. 학생별로 빈칸 답안과 프로그램 답안을 채점한다.
5. 지정한 정렬 옵션을 결과 연결 리스트에 적용한다.
6. CSV를 저장하고 저장 경로와 전체 수행 시간을 출력한다.

## 6. 점수 테이블

`ANS_DIR/score_table.csv`의 각 줄은 다음 형식이다.

```csv
1-1.txt,0.50
1-2.txt,0.50
2.c,1.00
```

발견된 모든 문제는 한 번씩 있어야 한다. 알 수 없는 문제, 누락·중복된 문제, 음수나 숫자가 아닌 배점은 오류 처리한다. 배점 `0`도 유효하다.

파일이 없으면 다음 두 생성 방식 중 하나를 대화형으로 선택한다.

1. 모든 빈칸 문제에 적용할 배점과 모든 프로그램 문제에 적용할 배점을 각각 입력한다.
2. 발견된 각 문제의 배점을 순서대로 입력한다.

입력값은 0 이상의 실수여야 하며, 생성한 파일은 소수점 둘째 자리까지 저장한다.

## 7. 채점 규칙

### 빈칸 문제

- 학생 답안이 정답 파일의 `:` 구분 후보 중 하나와 같으면 배점 전부를 얻는다.
- 앞뒤 공백과 토큰 사이 공백 차이는 무시한다.
- 기존 빈칸 파서가 지원하는 범위에서 연산자 우선순위와 괄호를 구문 트리로 비교한다.
- `+`, `*`, `|`, `&`, `||`, `&&`, `==`, `!=`의 피연산자 교환과 `<`, `>`, `<=`, `>=`의 방향 반전 표현을 비교한다.
- 학생 답안과 정답 후보의 끝 세미콜론 유무가 다르면 서로 다른 답으로 처리한다.
- 빈 파일, 괄호 불일치, 토큰화 실패는 오답이다.

### 프로그램 문제

- 정답: `gcc 정답.c -o 문제번호.exe`로 컴파일하고 실행 결과를 `문제번호.stdout`에 저장한다.
- 학생: `gcc 학생답안.c -o 문제번호.stdexe`로 컴파일하고 실행 결과를 `문제번호.stdout`에 저장한다.
- `-t` 대상 문제에는 컴파일 명령의 마지막에 `-lpthread`를 추가한다.
- 컴파일 종료 상태가 실패이면 0점이다.
- 컴파일 출력의 `warning:` 발생 횟수마다 `WARNING_PENALTY`(기본 `0.1`)를 배점에서 뺀다.
- 실행이 5초에 도달하면 프로세스를 종료하고 0점 처리한다.
- 정답과 학생의 표준 출력은 모든 공백 문자와 영문 대소문자를 무시하여 비교한다.
- 결과가 다르면 0점이다.

감점값과 제한 시간은 `ssu_score.h`의 `WARNING_PENALTY`, `EXECUTION_TIMEOUT_SECONDS`로 조정할 수 있다.

## 8. 옵션

### `-n <CSVFILENAME>`

기본 `ANS_DIR/score.csv` 대신 지정한 파일에 결과를 저장한다.

- 입력 형식: 상대 또는 절대 경로인 하나의 파일명
- 필수 조건: 이름이 `.csv`로 끝나고 부모 디렉토리가 이미 존재해야 함
- 기본값: `<ANS_DIR>/score.csv`
- 같은 파일이 있으면 덮어쓴다.

```sh
./ssu_score STUDENT ANS -n ./results/final.csv
```

### `-m`

기존 `ANS_DIR/score_table.csv`의 배점을 대화형으로 수정한다.

- 문제 입력: 확장자를 생략한 `3-1` 또는 실제 파일명 `3-1.txt`
- 종료 입력: `no`
- 새 점수: 0 이상의 실수
- 점수 테이블이 없으면 새로 만들지 않고 오류로 종료한다.
- 수정이 끝나면 점수 테이블을 저장한 뒤 변경 배점으로 정상 채점을 계속한다.

### `-c [STUDENTIDS ...]`

선택 학생의 총점을 학생 채점 완료 문구에 함께 출력하고, 출력 대상 학생만의 평균을 출력한다.

- 학번을 생략하면 모든 학생이 출력·평균 대상이다.
- 명시 학번은 최대 5개만 반영한다. 초과 인자는 안내 후 무시한다.
- 존재하지 않는 학번이 반영 대상 5개 안에 있으면 채점 전에 오류로 종료한다.

### `-p [STUDENTIDS ...]`

선택 학생의 오답을 `문제번호(배점)` 형식으로 출력한다. 오답 목록은 학생별 연결 리스트로 관리한다.

- 학번 생략, 최대 5개 제한, 존재 여부 검사는 `-c`와 같다.
- 모두 맞았으면 `none`을 출력한다.
- `-c`와 함께 사용하면 총점을 먼저 출력하고 오답 목록을 이어서 출력한다.
- `-c`와 `-p`를 함께 사용할 때 학번 그룹은 두 옵션 중 한 곳에만 쓸 수 있다.

```sh
./ssu_score STUDENT ANS -c -p 20230001 20230002
```

### `-t [QNAMES ...]`

선택 프로그램 문제를 `-lpthread`로 링크한다.

- 문제 번호는 확장자 없는 `12` 또는 파일명 `12.c`로 입력할 수 있다.
- 문제 번호를 생략하면 모든 프로그램 문제에 적용한다.
- 최대 5개만 반영하고 초과 인자는 안내 후 무시한다.
- 존재하지 않거나 `.c` 문제가 아닌 번호는 오류 처리한다.

### `-s <stdid|score> <1|-1>`

결과 CSV의 학생 행을 연결 리스트 병합 정렬로 재배치한다.

- 분류 기준 `stdid`: 학번 문자열
- 분류 기준 `score`: 총점
- 방향 `1`: 오름차순
- 방향 `-1`: 내림차순
- 총점이 같으면 학번으로 순서를 결정한다.

### `-e <DIRNAME>`

컴파일러가 출력한 경고·오류 내용을 `<DIRNAME>/<학번>/<문제번호>_error.txt`에 저장한다.

- 상대 또는 절대 디렉토리 경로를 허용한다.
- 디렉토리가 없으면 생성한다.
- 같은 디렉토리가 있으면 기존 내부 내용을 먼저 비운다.
- 이번 채점에서 컴파일 진단이 실제로 발생한 학생의 하위 디렉토리만 만든다.
- 루트, 현재 작업 디렉토리, 학생 디렉토리, 정답 디렉토리처럼 위험한 초기화 대상은 거부한다.

### `-h`

사용법을 출력한다. 학생·정답 디렉토리 없이 `./ssu_score -h`로만 사용한다. 다른 인자나 옵션과 함께 쓰면 사용법을 출력하고 오류로 종료한다.

## 9. 결과 CSV

```csv
,1-1.txt,1-2.txt,2.c,sum
20230001,0.50,0.50,0.90,1.90
20230002,0.00,0.50,0.00,0.50
```

- 첫 행: 문제 파일명과 `sum`
- 이후 행: 학번, 문제별 획득 점수, 총점
- 모든 점수는 소수점 둘째 자리까지 기록한다.
- `-s`가 없으면 학번 오름차순, 있으면 지정 기준과 방향을 따른다.

## 10. 확인한 테스트

프로젝트와 함께 만든 별도 검증 자료에서 다음을 확인했다.

- 빈칸 복수 정답과 교환·관계 연산 동치 판정
- 프로그램 출력의 대소문자·공백 무시
- 컴파일 경고 1건에 대한 0.1점 감점
- 컴파일 오류 0점과 `-e` 진단 파일 저장
- 무한 루프 프로그램의 5초 제한 및 0점 처리
- `-t`의 `pthread` 프로그램 링크
- `-c`/`-p` 선택 출력과 선택 대상 평균
- `-s score -1` 결과 행 정렬
- `-n` 상대 경로 저장
- 점수 테이블 최초 생성과 `-m` 수정
- 존재하지 않는 학번과 잘못된 옵션 인자 거부

검증 자료는 완성본 바깥의 `../tests`와 `../tests_create`에 있으며 제출물에는 포함하지 않아도 된다.
